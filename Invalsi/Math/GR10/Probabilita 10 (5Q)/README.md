# Moodle-Cartridges
Questo repository contiene una raccolta di Moodle Cartridges per i quiz delle prove Invalsi di probabilita. 
Ci sono tre tag: 2entry, tree e defpro che definiscono una partizione di questi test.  Per i  tag aggiuntivi 2entry defpro tree solo uno di questi e'assegnato e tree e'per i diagrammi ad albero, 2entry per le tabelle a doppia entrata e defpro per tutto il resto.
